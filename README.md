# 狼人杀游戏 0.1.0

一个支持语音交互的命令行狼人杀游戏，支持一名人类玩家和多个 AI 玩家对战。

## 主要特性

- 语音交互：支持语音输入和语音合成输出
- AI 玩家：基于 OpenAI API 的智能对话系统
- 完整角色：狼人、预言家、女巫、平民等
- 游戏流程：包含夜晚行动、白天讨论、投票环节
- 实时反馈：所有行动和结果都有清晰的提示

## 安装依赖

```bash
pip install openai speech_recognition pyttsx3
## 运行方法
```bash
python langRenSha6.0.py
 ```

## 游戏流程
1. 游戏初始化：
   
   - 6名玩家（1名人类 + 5名AI）
   - 随机分配角色
2. 每轮游戏包含：
   
   - 夜晚阶段（角色行动）
   - 白天阶段（自由发言）
   - 投票阶段（放逐玩家）
3. 游戏结束条件：
   
   - 狼人全部出局：好人阵营胜利
   - 狼人数量大于等于好人：狼人阵营胜利
## 角色说明
- 狼人：每晚可以选择一名玩家袭击
- 预言家：每晚可以查验一名玩家的身份
- 女巫：可以使用解药救人
- 平民：没有特殊技能，靠推理获胜
## 操作说明
1. 语音输入：
   
   - 按提示说话
   - 语音识别失败时可以使用键盘输入
2. 角色行动：
   
   - 按照提示选择目标
   - 输入对应的数字或选项
3. 投票环节：
   
   - 说出要投票的玩家名字
   - 确认投票结果
## 注意事项
1. 确保麦克风正常工作
2. 保持网络连接稳定
3. 语音输入时环境要安静
4. API_KEY 需要自行配置
